# SEATS — ใครนั่งเก้าอี้ไหนในโปรเจกต์นี้

> เขียนชื่อคนจริง · ช่องไหนยังว่างให้เขียน `— ยังไม่มี` **ห้ามเดาว่าจะถามใคร**
> สองเก้าอี้เป็นคนเดียวกันได้ แต่ต้องเขียนชื่อซ้ำให้เห็น

| เก้าอี้ | คน | ติดต่อทาง | หมายเหตุ |
|---|---|---|---|
| `operator` | โด่ง (owner) | chat ในเวิร์กสเปซนี้ (ผ่าน PM; ส่วนมากส่งต่อผ่าน Atom) | ผู้พัฒนาที่รันโต๊ะนี้ · เจ้าของ scope และงบ (harness `CLAUDE.md` §2) |
| `customer` | `skipped` | | เจ้าของทำใช้เอง · คนที่เขาเชิญ (ครอบครัว ทีม) เป็นผู้ใช้ ไม่ใช่ลูกค้า คำของพวกเขามาถึงโต๊ะผ่านเจ้าของเท่านั้น · **โต๊ะนี้ไม่มีตรา `customer-validated` เลย** |
| `pm` | → operator | | ไม่มีคนจริงนั่ง |
| `sa` | → operator | | ไม่มีคนจริงนั่ง · stack, DB และวิธีรัน dev server เป็นของเจ้าของ (ยังไม่กำหนด) |
| `designer` | — ยังไม่มี | | |
| `dev` | → operator | | ไม่มีคนจริงนั่ง |
| `qa` | — ยังไม่มี | | QA คน (มนุษย์) ยังไม่มี · AI QA ทำงานตามปกติ |
| `platform` | → operator | | เซิร์ฟเวอร์ · release · deploy |

**เก้าอี้ว่างไม่ใช่เรื่องผิด แต่ต้องพูดออกมา** — งานที่ต้องให้เก้าอี้นั้นตัดสิน จะค้างจนกว่าจะมีคนนั่ง
