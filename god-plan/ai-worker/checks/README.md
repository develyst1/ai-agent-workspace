# Desk checks

`ai-worker/checks.json` holds this desk's stop-the-action checks, run by the workspace hook `scripts/hooks/desk-checks.sh` on every Write/Edit/MultiEdit and every Bash `>`/`>>` into this desk. A check is added only when a mistake really happened: its `born` names the `FAILURES.md` entry behind it (`"born": "F-NNN YYYY-MM-DD"`), or `check-hygiene.mjs` FAILs it (harness §15). Each check has `id`, `born`, `when.write` (a path glob relative to the desk), one of `require` (regex the file must contain after the write) · `forbid` (regex the written text must not contain) · `forbid_values_from` (a git-ignored file in this folder, `checks/<name>.local.txt`, one value per line, never printed), and a `message` that names the CORE / RUNBOOK line holding the rule. Everything else stays a reminder.
