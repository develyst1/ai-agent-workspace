# SEATS — ใครนั่งเก้าอี้ไหนในโปรเจกต์นี้

> เขียนชื่อคนจริง · ช่องไหนยังว่างให้เขียน `— ยังไม่มี` **ห้ามเดาว่าจะถามใคร**
> สองเก้าอี้เป็นคนเดียวกันได้ แต่ต้องเขียนชื่อซ้ำให้เห็น

| เก้าอี้ | คน | ติดต่อทาง | หมายเหตุ |
|---|---|---|---|
| `operator` | เจ้าของ (คุณโด่ง) | chat ในเวิร์กสเปซนี้ | ผู้พัฒนาที่รันโต๊ะนี้ · เจ้าของ scope และงบ (harness `CLAUDE.md` §2) · เป็นคนสอน และคุยกับลูกค้าบน **Fastwork** |
| `customer` | ผู้เรียน ("the learner") — **ไม่เขียนชื่อหรือข้อมูลส่วนตัว** | **ผ่านเจ้าของเท่านั้น** (Fastwork) | คนที่จ่ายเงินและเซ็นรับ · **คนเดียวที่ validate ได้** · operator นั่งแทนไม่ได้ · คำของผู้เรียนเข้าโต๊ะผ่านเจ้าของเท่านั้น ตรา `customer-asked` / `customer-validated (วันที่ + ช่องทาง)` |
| `pm` | Porter (AI) | `inbox/PM.md` | คนเดียวที่คุยกับเจ้าของ · ไม่คุยกับผู้เรียนโดยตรง |
| `sa` | Sober (AI) | `inbox/SA.md` | ออกแบบหลักสูตร และโครงสร้างโฟลเดอร์ของ repo |
| `designer` | → operator | | |
| `dev` | Fern (AI, FE) | `inbox/FE.md` | เขียนสไลด์ หน้าบทเรียน และโค้ดตัวอย่าง |
| `qa` | Tanya (AI) | `inbox/QA.md` | ลองทำทุกแบบฝึกหัดเอง · ไม่มี QA ที่เป็นคน |
| `platform` | → operator | | เซิร์ฟเวอร์ · release · deploy |

**เก้าอี้ว่างไม่ใช่เรื่องผิด แต่ต้องพูดออกมา** — งานที่ต้องให้เก้าอี้นั้นตัดสิน จะค้างจนกว่าจะมีคนนั่ง
