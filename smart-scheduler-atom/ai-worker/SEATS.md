# SEATS — ใครนั่งเก้าอี้ไหนในโปรเจกต์นี้

> เขียนชื่อคนจริง · ช่องไหนยังว่างให้เขียน `— ยังไม่มี` **ห้ามเดาว่าจะถามใคร**
> สองเก้าอี้เป็นคนเดียวกันได้ แต่ต้องเขียนชื่อซ้ำให้เห็น

| เก้าอี้ | คน | ติดต่อทาง | หมายเหตุ |
|---|---|---|---|
| `operator` | — ยังไม่มี | chat ในเวิร์กสเปซนี้ | ผู้พัฒนาที่รันโต๊ะนี้ · เจ้าของ scope และงบ (harness `CLAUDE.md` §2) |
| `customer` | — ยังไม่มี | | คนที่จ่ายเงินและเซ็นรับ · **คนเดียวที่ validate ได้** · operator นั่งแทนไม่ได้ |
| `pm` | — ยังไม่มี | | คนเดียวที่คุยกับ customer |
| `sa` | — ยังไม่มี | | เจ้าของแนวทางเทคนิค |
| `designer` | — ยังไม่มี | | |
| `dev` | — ยังไม่มี | | |
| `qa` | — ยังไม่มี | | |
| `platform` | — ยังไม่มี | | เซิร์ฟเวอร์ · release |

**เก้าอี้ว่างไม่ใช่เรื่องผิด แต่ต้องพูดออกมา** — งานที่ต้องให้เก้าอี้นั้นตัดสิน จะค้างจนกว่าจะมีคนนั่ง
