## Defects
### DEF-1 — W-4 "Incorrect email or password" alert is unreadable on the dark theme (contrast 1.14:1) — MAJOR — **FIXED (TASK-014), verified on SIT 2026-09-22 round 2: 14.16:1**
- Environment: SIT `https://possibility.develyst.online`, landing sign-in form, TH and EN, desktop and 375 px.
- Repro (from a clean state): 1. open `/` signed out. 2. type any registered email + a wrong password. 3. click `เข้าสู่ระบบ` / `Sign in`.
- Expected: W-4 `อีเมลหรือรหัสผ่านไม่ถูกต้อง` / `Incorrect email or password.` clearly readable (REQ-007 AC-6: body text ≥ 4.5:1).
- Actual: the antd `Alert` renders with the **light** error background `rgb(255,244,240)` but the theme's **off-white** text `rgba(235,231,224,0.88)` → contrast **1.14:1**; the message is a faint smear (see screenshot description in §Evidence). The W-3 (short password) and W-5 (email taken) messages are *form-item* errors (red on dark) and read fine — only the `Alert`-based message is affected. W-6 (REQ-003 failure) uses the same `Alert` and is very likely affected too (could not trigger it on SIT).
- Evidence: computed styles read from the DOM (`color: rgba(235, 231, 224, 0.88)`, `background: rgb(255, 244, 240)`, ratio 1.14, 16 px); screenshot viewed live 2026-09-22 (alert box visible, text near-invisible).
- Attribution (per project rule): introduced with the REQ-007 dark theme (TASK-013) on top of TASK-012's alert — the `Alert` background/text tokens were not themed together. Reached the engineers via Porter → Sober.
