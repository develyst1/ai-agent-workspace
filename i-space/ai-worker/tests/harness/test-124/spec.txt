สมุดรายจ่ายประจำวัน — เว็บหน้าเดียวไว้จดรายจ่ายของแต่ละวัน
1. ใส่รายจ่ายได้: จำนวนเงิน (บาท), หมวด (อาหาร / เดินทาง / ของใช้ / อื่นๆ), หมายเหตุสั้นๆ แล้วกดปุ่ม "บันทึก"
2. แสดงรายการรายจ่ายของวันนี้ รายการล่าสุดอยู่บนสุด พร้อมเวลาที่บันทึก
3. แสดงยอดรวมของวันนี้ และยอดรวมแยกตามหมวด
4. ลบรายการที่ใส่ผิดได้ โดยถามยืนยันก่อนลบ
5. ข้อมูลเก็บในไฟล์ JSON บนเครื่อง ปิดแล้วเปิด server ใหม่ ข้อมูลยังอยู่ครบ
6. จำนวนเงินต้องเป็นตัวเลขมากกว่า 0 ถ้าใส่ผิดให้ขึ้นข้อความบอกเป็นภาษาไทย และไม่บันทึก
7. รันที่ http://127.0.0.1:3920 ไม่ต้อง login ไม่มีฐานข้อมูล ข้อความบนหน้าเป็นภาษาไทยทั้งหมด
