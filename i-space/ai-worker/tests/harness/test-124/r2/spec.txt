สมุดยืม-คืนหนังสือในออฟฟิศ — เว็บหน้าเดียวไว้ดูว่าหนังสือเล่มไหนอยู่กับใคร
1. เพิ่มหนังสือได้: ชื่อหนังสือ, ผู้แต่ง แล้วกดปุ่ม "เพิ่มหนังสือ"
2. แสดงรายการหนังสือทั้งหมด พร้อมสถานะ "ว่าง" หรือ "ถูกยืม" และชื่อคนยืม
3. ยืมได้: กด "ยืม" ที่หนังสือที่ว่าง ใส่ชื่อคนยืม แล้วหนังสือเปลี่ยนเป็นถูกยืม พร้อมวันที่ยืม
4. คืนได้: กด "คืน" ที่หนังสือที่ถูกยืม ถามยืนยันก่อน แล้วกลับเป็นว่าง
5. ค้นหาหนังสือจากชื่อหรือผู้แต่งได้ พิมพ์แล้วรายการกรองทันที
6. ข้อมูลเก็บในไฟล์ JSON บนเครื่อง ปิดแล้วเปิด server ใหม่ ข้อมูลยังอยู่ครบ
7. ชื่อหนังสือและชื่อคนยืมห้ามว่าง ถ้าว่างให้ขึ้นข้อความบอกเป็นภาษาไทย และไม่บันทึก
8. รันที่ http://127.0.0.1:3930 ไม่ต้อง login ไม่มีฐานข้อมูล ข้อความบนหน้าเป็นภาษาไทยทั้งหมด
ไม่ทำ: แจ้งเตือนเกินกำหนด, หลายสาขา, ส่งออกไฟล์, deploy ขึ้น server
