# SEATS — ใครนั่งเก้าอี้ไหนในโปรเจกต์นี้

> เขียนชื่อคนจริง · ช่องไหนยังว่างให้เขียน `— ยังไม่มี` **ห้ามเดาว่าจะถามใคร**
> สองเก้าอี้เป็นคนเดียวกันได้ แต่ต้องเขียนชื่อซ้ำให้เห็น

| เก้าอี้ | คน | ติดต่อทาง | หมายเหตุ |
|---|---|---|---|
| `operator` | โด่ง (owner) | chat ในเวิร์กสเปซนี้ (ผ่าน PM; ส่วนมากส่งต่อผ่าน Atom) | ผู้พัฒนาที่รันโต๊ะนี้ · เจ้าของ scope และงบ (harness `CLAUDE.md` §2) · I-Space เป็นผลิตภัณฑ์ของเขาเอง |
| `customer` | `skipped` | | ผลิตภัณฑ์ของเจ้าของเอง ยังไม่มีลูกค้า · **โต๊ะนี้ไม่มีตรา `customer-validated` เลย** |
| `pm` | → operator | | ไม่มีคนจริงนั่ง · ยังไม่มีลูกค้าให้คุย |
| `sa` | → operator | | ไม่มีคนจริงนั่ง · เจ้าของแนวทางเทคนิค |
| `designer` | → operator | | เจ้าของอนุมัติดีไซน์ (owner duty: design-approve) |
| `dev` | → operator | | ไม่มีคนจริงนั่ง |
| `qa` | — ยังไม่มี | | QA คน (มนุษย์) ยังไม่มี · AI QA ทำงานตามปกติ |
| `platform` | → operator | | เซิร์ฟเวอร์ · release · deploy (owner duty: deploy) · CAW production รัน Claude CLI บนเซิร์ฟเวอร์ที่ deploy (subscription) — ของเจ้าของ |

**เก้าอี้ว่างไม่ใช่เรื่องผิด แต่ต้องพูดออกมา** — งานที่ต้องให้เก้าอี้นั้นตัดสิน จะค้างจนกว่าจะมีคนนั่ง
