## 2. งานหน้าบ้านที่ทำให้ฟรี (แสดงมูลค่า แล้วลด 100%) รวมมูลค่า 3,150 บาท
นับเฉพาะงานที่ลูกค้าขอเพิ่มหลังขึ้น uat (26 ต.ค.) ส่วนฝั่งเราทำ back end, หน้าจอ Dashboard ปาล์มทำ
| รายการ | วันทำงาน | มูลค่า (บาท) |
|---|---|---|
| SOM Dashboard รอบ 1: นับตามนิยามของลูกค้า ไม่นับคอร์สที่ยกเลิก (REQ-5002) | 3.5 | 900 |
| SOM Dashboard รอบ 2: เลือกช่วงเวลาได้ (ทั้งหมด / from–to / เดือน), Total นับเฉพาะ Active, Coach capacity ตามประเภทครู (REQ-5004) | 4.5 | 1,200 |
| SOM Dashboard รอบ 3: Coach Capacity ใหม่ + นับชั่วโมง ECA/Camp (REQ-5009) | 0.5 | 150 |
| SOM Dashboard รอบ 4: Gender/Nationality, กิจกรรมแยกแพ็ก, กราฟวงกลม 3 ชุด | ~2 | 550 |
| ย้ายคอร์สไปสาขาอื่น (พี่โด่งให้ฟรี) | 1–1.5 | 350 |
รวม 900 + 1,200 + 150 + 550 + 350 = 3,150 บาท
