ปาล์ม ทีม backend เช็ค §9 ในเอกสาร `backend-daily-report.md` กับโค้ดหลังบ้านแล้ว ส่วนใหญ่ตรงตามที่ปาล์มเข้าใจ มี 3 เรื่องที่ควรรู้ก่อนเทียบตัวเลข (§9.3):

1. **ตัวเลข On leave กับ Total booked ของ backend จะสูงกว่า fallback ในบางวัน**
   `/calendar` โชว์แค่ 1 แถวต่อครู + เวลา ถ้าเด็กลาแล้วมีคนอื่นมาจองช่องเดิม แถวลาจะหายจากปฏิทิน fallback เลยไม่เห็น backend นับจากข้อมูลจริง เลยนับได้ครบ

2. **ตัวเลข Cancelled ของ backend จะต่ำกว่า fallback ในบางวัน**
   ที่นั่งในคลาสกลุ่มเก็บเป็นแถว `COURSE_PACKAGE` ที่มี `group_id` ถาดคลาสที่ยกเลิกของ `/calendar` ไม่ได้กรองที่นั่งกลุ่มออก fallback เลยนับที่นั่งกลุ่มที่ยกเลิกรวมเข้าไปด้วย ส่วน backend ตัดที่นั่งกลุ่มออกทุกช่อง ตามข้อ §1 ของปาล์ม

3. **คำตอบ Q3 จากข้อมูลจริง:** Camp เก็บเป็น **1 แถวต่อครู 1 คนต่อ 1 ชั่วโมง** ส่วน ECA กับคาบเรียนปกติเป็น 1 แถวต่อคาบ

4. **(เพิ่มหลังเทสบน sid 10-13) คาบที่อยู่นอกช่วง 09:00–17:00 นับครบแล้ว** `/calendar` คืนแค่ช่วงเวลา 09:00–17:00 คาบตอน 08:00 หรือ 18:00–21:00 เลยไม่เคยถูกนับใน fallback ส่วน backend นับทุกคาบของวันนั้น

ตอนเทียบตัวเลขตาม §9.3 ถ้าเจอข้อ 1, 2 หรือ 4 ต่างกัน ถือว่าปกติ backend เป็นตัวที่ถูก
Q1–Q6 ฝั่ง backend ใช้ค่าชั่วคราวตามที่ปาล์มใส่ไว้ใน `daily-report.ts` ทุกข้อ ตัวเลขจะได้ไม่กระโดดตอนสลับ

5. **(เพิ่ม 10-13) ขวัญเลือกแล้ว Total booked = Confirmed + On leave ไม่นับ Pending/Extended** (ขวัญตอบ: *"ไม่นับคลาสที่ยังไม่คอนเฟิร์มค่า"*) backend เปลี่ยนตามนี้แล้ว หน้าจอใช้ตัวเลขจาก backend อยู่แล้ว ไม่ต้องแก้หน้าจอ แต่ค่าชั่วคราวใน `daily-report.ts` กับข้อ §2 ในเอกสารควรอัปเดตให้ตรงกัน
