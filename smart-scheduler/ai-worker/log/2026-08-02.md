2. **It grants nothing new.** The session *carries* a token the holder already had; it converts an API session
   into a browser session rather than creating authority. If the script leaks it does nothing — `AUTH_SECRET`
   already protects every session in the product.
3. **It cannot drift into production**, because there is nothing to leave accidentally enabled.
