## Contract (pinned — 907 is built to this)
- **`POST /v1/stock/products`** (CEO) body `{ code, name, category, priceSatang, commissionGroup: string|null, active, openingQuantity }` → creates a `bo.item`: `external_source = stock`, `external_ref = code` (unique, case-insensitive — reuse 904's dup rule), `direction = INCOME`, `ceiling_qty = NULL`, `remaining_qty` seeded by **ONE opening movement** of `openingQuantity` (value_minor 0, like the import's opening), `unit_price_minor = priceSatang`, `commission_group = commissionGroup` (the NAME only — commission is per-GROUP, the rate is a future managed-groups task, not stored here), category attached via the «Category» tag group.
- **`PATCH /v1/stock/products/:id`** (CEO) body `{ name?, priceSatang?, category?, commissionGroup?, active? }` → a field edit (reuse `updateItem`): **no movement, never changes the balance.** (A balance change comes only from import / a stock-out / an explicit adjustment.)
- **Validation:** price integer satang ≥0; code ≤64, name ≤200; opening quantity whole ≥0; `409` (or your 904 code) on a duplicate code naming it.
- **No per-product commission amount** (see commission-is-per-group above). No location/branch.
