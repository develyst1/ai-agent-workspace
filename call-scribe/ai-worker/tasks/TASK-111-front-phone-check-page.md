## What to do

One page, `/check`, for the owner to run on his Oppo. It answers two questions and **stores and uploads nothing**, because he will use his own recording on it.

1. No login, and **no call to the back at all**, not even `/health`. It must work with no back running.
2. **Record:** start and stop, `MediaRecorder` with pieces held in memory only (not IndexedDB). After stop, show the length and a plain `<audio controls>` of that recording, so he can hear whether it holds everything. It is gone when the page closes. Wake lock is **not** used here: the check is about the screen being off.
3. **Strip:** a file input for a video. Run TASK-108's strip, with no upload. Show picked size, output size, seconds taken. Then discard the output.
4. **The page died:** set `localStorage["cs_check_strip_running"]` before a strip, clear it after. If it is found set when the page opens, show the "page died" result and clear it. This flag holds no audio and no file name. Separate from the main app's flag.
5. A strip that throws shows the "failed" result. There is **no fallback upload here**.

Playback is on this page only. The app's Out of Scope still holds.

You decide: layout. Note it.
